# 범퍼 CAD

파라미터 YAML 하나로 범퍼를 생성합니다. 출력용 STL, URDF용 메시, URDF 파라미터가 함께 만들어집니다. 버전을 추가하려면 YAML을 복사해서 값을 바꾸고 다시 생성합니다.

```bash
cd src/pinky_soccer_description/cad/bumper
source /opt/ros/jazzy/setup.bash && source ~/pinky-soccer/install/setup.bash
python3 generate_bumper.py bumper_v1.yaml
```

필요한 것: Blender 4.2 이상(`blender`가 PATH에 있거나 `--blender <경로>`), `numpy`, `pyyaml`, `trimesh`(MuJoCo 설치 때 함께 설치됨), source된 워크스페이스.

| 생성 파일 | 용도 |
|---|---|
| `print/<name>_print.stl` | **출력용**. mm 단위, `print.orientation` 방향 |
| `print/<name>_report.txt` | 무게, 크기, 메시 품질, 끼운 상태와 끼우는 중의 간섭 검사 결과 |
| `../../meshes/visual/<name>.stl` | URDF visual (m, `bumper_link` 좌표계 = 무게중심) |
| `../../meshes/collision/<name>_collision.stl` | URDF collision (앞판 상자만) |
| `../../config/<name>_params.yaml` | `bumper_params_file:=`로 넘기는 URDF 파라미터 (생성 파일, 직접 수정 금지) |

## v1: ㄷ자 범퍼 + 스냅 갈고리

```text
        z = 0 단면, 위에서 본 모습 (왼쪽 절반, base_link mm)

     |y| 38.5 ┌──────────────────────┐╮   ← 앞 모서리 R3
     |y| 36.5 │ ┌────────────────────┘ │
  갈고리 ( ⬡ )─┘ │ ← 꺾임부: 두 판 앞     │  앞판 (초음파 원뿔 구멍)
    |y| 31.55 └    가장자리에 닿음       │
           x 16.5 20.5 22.5          37.5 41.5
```

- **앞판**: IR 기판(x 36.5) 바로 앞(x 37.5~41.5)에 섭니다. 너비는 섀시 폭 ±38.5mm이고, 앞 모서리는 반지름 3mm로 둥글게 처리해 거의 직각입니다. 높이는 아래 판 밑면부터 중간 판 윗면까지(지면 9~51mm)입니다.
- **초음파 구멍**: 센서 원통 둘레로 0.5mm 여유를 두고, 원통 앞면부터 반각 25°로 넓어집니다(빔은 약 15°).
- **옆벽**(두께 2mm): 섀시 바깥쪽(\|y\| 36.5~38.5)을 따라 판 앞 가장자리(x 20.5)까지 이어집니다. 갈고리를 끼울 때 이 벽이 안쪽으로 휩니다.
- **꺾임부**(x 20.5~22.5): 안쪽으로 꺾이는 부분입니다. 뒷면이 아래 판과 중간 판의 앞 가장자리에 닿아서, 공을 미는 힘을 판이 받습니다.
- **갈고리**(두께 2mm): 두 판 사이로 들어가 앞쪽 기둥을 감쌉니다.
  - 뒤쪽은 안쪽에서부터 75°(`wrap_deg`)를 감싸고, 끝은 완전한 반원(반지름 1mm)입니다.
  - 앞쪽은 기둥 정면까지 외접원을 따라간 뒤, 반지름 2.5mm 볼록 곡면(`front_wrap_fillet`)으로 옆벽 바깥면에 S자로 이어집니다.
  - 안쪽 윤곽은 육각형이 아니라 **외접원**(r 2.30)에 여유 0.15mm를 더한 원입니다. 실물 육각의 방향을 알 수 없기 때문입니다.
  - 높이는 두 판 간격 35mm에서 0.4mm를 뺀 34.6mm입니다(위아래 0.2mm씩 여유).
- **둥근 모서리**(`fillets`): 휘는 옆벽이 앞판과 만나는 뿌리는 2mm, 꺾임부 앞면 위아래는 각 2.5mm입니다. 꺾임부 앞면이 두 반지름의 합보다 짧으면 두 반지름을 같은 비율로 줄여서 접선으로 이어지는 S자로 만듭니다(v1: 4.95mm 면에 각 2.47mm).
- **메시 정리**: 모든 불리언 연산이 끝난 뒤 메시를 정리합니다(겹친 꼭짓점 병합, 퇴화 면 제거, 같은 평면 분할 제거). `edge_chamfer`를 주면 그다음에 날카로운 모서리(50° 이상)에만 챔퍼를 넣습니다. 기본값 0은 외형 차이가 작은 반면 곡면 가장자리의 미세한 면을 피합니다.

### 장착 방법

1. 범퍼를 로봇 정면에 맞추고 수평으로 뒤로 밉니다. 초음파 원통은 구멍으로 들어갑니다.
2. 갈고리 끝(반원)이 기둥 아래쪽을 타고 넘으며 옆벽이 휩니다(갈고리 끝 기준 최대 1.3mm). 꺾임부가 판 가장자리에 닿을 때 갈고리가 기둥 뒤로 넘어가며 걸립니다.
3. **뺄 때**: 갈고리가 기둥 뒤를 75° 감싸서 당기기만 해서는 잘 빠지지 않습니다. 바퀴 앞쪽(x 28~37)에서 양쪽 옆벽을 안쪽으로 누른 채 앞으로 당깁니다.

### 끼울 때의 휨 검사

생성기는 범퍼를 10mm 앞에서 0.1mm씩 밀어 넣으며, 위치마다 기둥을 넘는 데 필요한 만큼만 옆벽을 휘게 하고 로봇 메시와의 충돌을 검사합니다.

- 옆벽(앞판~꺾임부)은 외팔보, 꺾임부·팔·갈고리는 그 끝에 붙은 단단한 덩어리로 봅니다. 그래서 갈고리는 평행이동이 아니라 비스듬히 돌아가며 들어갑니다.
- 감싸는 각도별 결과(갈고리 두께 2mm):

| `wrap_deg` | 갈고리 끝 휨 | IR 기판 가장자리와 최소 간격 |
|---|---|---|
| 90 | 1.95mm | -0.38mm (닿음) |
| 85 | 1.70mm | -0.13mm (닿음) |
| 80 | 1.50mm | +0.06mm |
| **75 (v1)** | **1.30mm** | **+0.26mm** |
| 70 | 1.10mm | +0.46mm |

옆벽 뿌리의 변형률은 0.91%입니다(PLA 스냅핏 권장치 약 2% 이하).

### 출력

- `print.orientation: upright`(기본)는 바닥면을 베드에 둡니다. 옆벽이 필라멘트 방향으로 휘어서 반복해서 끼워도 잘 견딥니다.
  - **서포트 필요**: 갈고리 아래(베드에서 4.2mm 떠 있음)와 초음파 구멍 윗부분에 서포트가 필요합니다. 서포트 블로커나 트리 서포트를 권장합니다.
- `front_down`은 앞면을 베드에 두는 방식입니다. 서포트가 필요 없지만, 옆벽이 층과 층 사이 방향으로 휘어서 반복해서 끼우면 층이 갈라질 수 있습니다.
- 크기는 28.9 × 77 × 42mm(upright), 무게는 약 16g입니다(PLA, 채움 80% 가정).
- 실물의 판 간격, 기둥 위치와 크기를 먼저 재 보고, 다르면 YAML에 반영해서 다시 생성하세요.

### 검증

| 항목 | 결과 |
|---|---|
| 메시 | 몸체 1개, watertight, 0.05mm 미만 모서리 40개(모두 평면 위) |
| 끼운 상태에서 공식 visual 메시와 간섭(0.05mm 초과) | 0 |
| 끼우는 중(휨 시뮬레이션) 로봇 부품과 충돌 | 0 (IR 기판 간격 +0.26mm) |
| 1mm 이내로 가까운 부품 | 판 가장자리(의도한 접촉), 기둥 외접원 0.15mm, 초음파 원통 0.5mm |
| MuJoCo 물리 테스트(공 밀기, 기울기) | 통과 |
| Gazebo 공 밀기 | 공이 범퍼 앞에 유지됨 |
| 실물 끼움 | **미검증** (출력 후 확인) |

간섭 검사는 공식 **visual** 메시를 기준으로 합니다. 실물과 CAD는 다를 수 있으니 처음에는 시험 출력으로 맞춤을 확인하세요.
