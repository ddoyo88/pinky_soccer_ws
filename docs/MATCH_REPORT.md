## 3. 흐름(추세)

- **안전:**
  - 라인 초과는 r2s1부터 r5s1까지 0이었습니다. r5s2에서 공이 바로 앞에 있는데 안 보이는 상황으로 한 번 다시 나왔고, 고친 뒤 r5s3에서 다시 0이 됐습니다.
  - 로봇 접촉은 15세트 중 2세트에서만 나왔고, 총 2.5초였습니다. 마지막 수정 이후에는 0입니다.
  - 뒤집힘은 한 번도 없었습니다.
- **골대 끼임:** r3s2 수정 이후로 들어 올리는 구조가 필요한 끼임이 없습니다.
- **공 탐색:** 라운드 5에서 늘어난 원인은 중앙 재배치였습니다. 마지막 두 수정으로 크게 줄었습니다(r5s2 58번 → r5s3 22번).
- **막힘(10초 정지):** 세트당 0–5번이었습니다. 원인을 하나씩 없앴고, 남은 것은 중앙 재배치 직후 상황뿐입니다(마지막 수정이 이것을 다룸).
- **경기 시간:** 3.2분에서 11.4분까지였습니다. 초반 라운드에 비해 라운드 4–5는 4–8분으로 안정됐습니다.

## 4. 남은 과제

- r5s3 이후의 마지막 수정(지연 프레임 무시)은 아직 경기로 확인하지 않았습니다. 1세트를 더 돌려 확인하면 됩니다.
- 라인에 붙은 공은 여전히 세트당 1–7번 나옵니다. 로봇이 라인을 넘지 않도록 막다 보니 라인 위 공을 꺼내지 못하는 구조적 한계이고, 심판이 공을 중앙으로 옮겨서 처리합니다. 근본적으로 줄이려면 라인 가드를 넣은 상태로 RL을 다시 학습해야 합니다(라인 근처 공을 비스듬히 빼내는 법을 배우도록).
- 실제 로봇에서는 같은 가드가 라이다와 카메라 데이터로 동작합니다. 시뮬레이션 결과를 실제 로봇 테스트로 확인해야 합니다.

## 사용자 피드백으로 바꾼 경기 방식 (이 커밋 = 태그 `straight-play-2026-11-25`)
- **심판:** 공을 자동으로 옮기지 않음. 골라인/사이드라인 밖, 라인에 붙어 로봇이 못 꺼내는 공 → 안내만, 사람이 "공 가운데로" 버튼 (`auto_ball_reset:=true`는 자동 테스트용)
- **직선 플레이 (`rl_policy.straight_cmd`):** RL 정책의 지그재그(회전 방향 바뀜 1.8회/초) 대신 접근·드리블을 직선 제어 — 같은 시험 40경기에서 골 8→18, 회전 바뀜 0.3회/초 (`scripts/rl_smooth_eval.py`)
  - 공·골과 일직선이면 공으로 곧장 + 밀기, 골 쪽에 있으면 공 옆으로 돌아 뒤로, 방향이 틀어지면 제자리 회전 후 직진
  - 골대 60cm 안 + 상대가 공에서 50cm 밖: 뒤로 물러났다 최고 속도로 슛
  - 마주 섰을 때 공에 가까운 로봇이 가고 상대는 40cm 물러남 (최대 3초), 공이 코앞(18–20cm)이면 과감하게
  - 공이 경기장 밖이면 제자리 대기, 엔드라인 옆 공은 라인을 따라 골문 앞으로
- **킥오프:** 기다리는 로봇은 공 30cm 밖 (센터서클)
- **충돌 가드 축소:** 정지 거리 15.5 / 18 / 20cm (우선권 / 없음 / 양보), 감속 6cm
- **라인 가드:** 이미 라인에 걸친 로봇도 안쪽으로는 움직일 수 있게 (얼어붙던 버그)
- **시뮬레이터 실시간 (0.39배 → 1.0배):** 카메라 424×240 @10Hz, 틱 50Hz, 상태 20–25Hz, 화면 10Hz, 화면의 로봇은 단순 모양 (`simple_robots:=false`면 실제 모양, 약 0.66배)
